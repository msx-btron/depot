VirtIO

make posix, make qemu, and make sakamura build the hosted POSIX, VirtIO/QEMU, and Sakamura T-Kernel 2.0 kernels.

Technical Characteristics of the Computer/Console

ChipsetHosted POSIX / QEMU VirtIO / T-Kernel 2.0 Sakamura (src/cores/core_posix.c, src/cores/core_virtio.c, src/cores/core_tkernel.c)
BusVirtIO-PCI / VirtIO-MMIO (src/drivers/virtio/), host file-backed block devices
VideoSDL2 / VirtIO-GPU 2D linear framebuffer, TinyGL 3D rasterizer
Display1024×768 / 1280×1024 @ 32-bpp ARGB; B-System Workstation & LAPTOP shell
SoundSDL2 PCM / VirtIO-Sound stereo audio, Orchestra synthesizer
InputSDL2 / VirtIO-Input keyboard & mouse, POSIX terminal TTY
MemoryHosted virtual address space / 256 MB–1 GB QEMU RAM
CommunicationsVirtIO-Net Ethernet, host POSIX sockets, 16550A / stdio serial console
