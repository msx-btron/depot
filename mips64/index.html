MIPS Malta

make mips builds the MIPS Malta bare-metal kernel (make run-mips on QEMU malta).

Technical Characteristics of the Computer/Console

ChipsetMIPS32 24Kf / MIPS64 Malta Core LV (little-endian, src/cores/core_mips.c, T-Kernel 2.0)
BusGalileo GT-64120 System Controller, PCI / Intel 82371EB PIIX4 Southbridge, ISA
VideoPCI VGA / Bochs linear framebuffer (src/drivers/mips/)
Display800×600 / 1024×768 @ 32-bpp ARGB; serial console & B-System shell
SoundPIIX4 / AC'97 / PC speaker
Inputi8042 PS/2 keyboard & mouse, 16550A UART serial
Memory256 MB SDRAM (KSEG0 direct-mapped kernel space under QEMU malta)
Communications16550A NS16550 UART serial console (COM1), AMD PCnet PCI Ethernet
